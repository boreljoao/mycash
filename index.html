☁ Sincronizar entre aparelhos

Seus dados ficam no seu banco de dados Supabase (gratuito) e aparecem no computador e no celular.

Como criar o banco de dados (5 minutos, grátis)
  1. Acesse supabase.com, crie uma conta e um projeto novo (plano Free).
  2. No menu do projeto, abra SQL Editor, cole o código abaixo e clique em Run.
  3. Em Project Settings → API, copie a Project URL e a chave anon public.
  4. Cole aqui em cima, escolha um código de sincronização e clique em conectar.
  5. No celular, abra o site, repita o passo 4 com os mesmos dados. Pronto: tudo no mesmo lugar.
